# 社内固有の識別子をマスクする

マスクパネルの「キー」欄・「任意パターン」欄、およびプロセスIDマスクの
完全な挙動。マスクパネルの概要は
[社内固有の識別子をマスクする](../../README.ja.md#社内固有の識別子をマスクする)
（README）を参照してください。

まず使うのは **「キー」欄** です。伏せたいキー名をカンマまたは空白区切りで
並べる（例: `user, token`）と、その**値だけ**が `<MASKED>` に置き換わるので、
`user=hoge` は `user=<MASKED>` になりキー名は読めるまま残ります。
`key=value` / `key: value` とクォート付きの値（`token="abc"` →
`token="<MASKED>"`）に対応し、キー名は大文字小文字を無視してリテラルとして
扱うため、正規表現のメタ文字や非ASCIIのキー名（`契約ID`）もそのまま書けます
（`user` の指定で `superuser=x` のような別のキーは誤マスクしません）。

**「任意パターン」欄** は正規表現の一致箇所を全て `<MASKED>` に置き換える欄で、
キー欄では表せない対象に使います。不正な正規表現や処理が重いパターンでも、
効かなくなるのはそのマスクだけで、警告を出したうえで他のマスクは効き続けます。
2つの欄は同時に効き、どちらもパネルの状態として持ち、設定には保存しません。

プロセスIDのマスク（`Copy Masked Text` でも使えます）は、syslog形式の
`sshd[1234]:` と `pid=1234` / `pid: 1234` / `[pid 1234]` のようにpidと明記
された表記を `<PID>` に置き換えます。log4jのスレッド名 `[main]` や配列の
添字 `retries[3]` は誤マスクしません。
